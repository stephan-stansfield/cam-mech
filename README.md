# cam-mech

This repository contains code that uses optimization to generate cam shapes that may be used in the design of energy storage and return mechanisms for stand-to-sit and sit-to-stand assistance devices.

## Main files
`class_cam_generation.py` contains the functions that are called by other scripts to generate cam shapes. A set of keypoints are used to define coarse shapes for a compound cam mechanism, consisting of a gear ratio and angle for each keypoint and one overall scaling factor. Subsequent functions interpolate between keypoints to generate smooth cam shapes while ensuring convexity. Finally, functions are included to calculate force-displacement profiles associated with these compound cam shapes when used to store and return energy using cables and a spring element.

`generate_cams_si2st.ipynb` generates a set of compound cam mechanisms for sit-to-stand assistance by calling functions from `class_cam_generation.py` within a multi-objective optimization framework. Optimization targets and limits are input by the user to generate cams with desired characteristics.

`generate_cams_st2si.ipynb` generates a cam for stand-to-sit assistance that pairs with the energy storage cam of a previously generated compound cam mechanism for sit-to-stand assistance. This script employs optimization with a single objective, minimizing peak force, to generate the cam shape.

`generate_cams_si2st_no_opt.ipynb` generates a sit-to-stand assistance compound cam from a set of gear ratios and scaling factor without running an optimization. This script is useful to manually create a compound cam, or to further analyze or edit compound cam shapes that were previously generated using optimization.

## Subfolders
`analysis` contains scripts to analyze previously generated cam shapes, including extracting their force-displacement profiles and curve lengths.

`bistable_opt` contains MATLAB code to generate the rigid body member lengths and angles of a bistable switching mechanism to be used in a device that uses different cam profiles for sit-to-stand and stand-to-sit.

`CAD` contains SolidWorks files for physical prototypes created from the generated cam shapes.

`data` contains knee angle data used as input to generate cam shapes, as well as point clouds and force-displacement data of selected cam shapes generated by the optimization scripts.
